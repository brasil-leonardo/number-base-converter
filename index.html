Number Base Converter

This project is a numeric base converter, created as a simple and practical program to help programmers in their daily work.
It is hable to convert numbers in binary, octal, decimal and hexadecimal numerical bases.

Steps to use

  1. Select the numerical base who you like to convert;
  2. Write the number in the right field;
  3. See the number automacticaly converted in yours respectives fields.
